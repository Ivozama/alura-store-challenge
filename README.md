# Análisis de Datos Alura Store LATAM

### Autor: Ivan Zamaniego

## Descripción del Proyecto

Este proyecto analiza el desempeño de cuatro tiendas de Alura Store con el objetivo de identificar cuál presenta menor rendimiento y debería ser vendida para permitir una nueva inversión estratégica.

## Estructura del Proyecto
- `AluraStoreLatam.ipynb` → Notebook con análisis completo
- `README.md` → Documentación del proyecto

## Tecnologías Utilizadas

- Python 3
- Pandas
- Matplotlib
- Google Colab

## Cómo Ejecutar el Proyecto

1. Descargar el archivo `.ipynb`
2. Abrirlo en Google Colab o Jupyter Notebook
3. Ejecutar las celdas en orden

## Métricas Analizadas

- Facturación total
- Calificación promedio
- Costo promedio de envío
- Productos más y menos vendidos

## Conclusión

Se determinó que la **Tienda 4** presenta el menor desempeño financiero, por lo que se recomienda su venta como estrategia de optimización del negocio.
